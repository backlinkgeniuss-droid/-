울산출장마사지 이즈웹 적용 안내

1. 03_BODY.html 전체를 이즈웹 본문 HTML 코드 위젯에 붙여넣습니다. 기존 포항 BODY는 제거하고 교체합니다.
2. 02_HEAD_SCHEMA.html은 이즈웹 HEAD 추가 코드 영역에 넣습니다.
3. 01_META_REFERENCE.html은 메타 설정 참고용입니다. 이즈웹이 title/description/canonical/OG를 생성하면 관리자 SEO 설정에서 같은 값으로 수정하고, 이 파일을 중복 삽입하지 않습니다.
4. preview.html은 독립 미리보기 파일입니다. 이즈웹 본문에 붙이지 않습니다.
5. 전화/텔레그램 설정: 03_BODY.html 하단 UM_CONFIG의 phone과 telegram만 수정합니다. phone 예: '010-1234-5678', telegram 예: 'https://t.me/사용자명'. 빈 값은 비활성 상태입니다. 입력하면 화면의 전화번호와 모든 예약 버튼이 함께 변경됩니다. JS가 차단되면 버튼은 안전하게 비활성 상태를 유지합니다.
6. 이즈웹 고정 헤더가 있을 경우 UM_CONFIG.headerOffset 값을 실제 헤더 높이(px)로 설정합니다. 기본값 0입니다. 상위 빌더 래퍼에 overflow:hidden 등이 있으면 sticky가 제한될 수 있으므로 실제 페이지에서 확인합니다.
7. 이미지는 공개 GitHub의 ulsan-visit-20261002/assets/에서 불러옵니다. 저장소/파일 경로를 유지해 주세요.
8. 본문 가격은 요청한 기존 요금(전신 7/9만원, 아로마 8/10만원, 로미로미 10/12만원)을 유지했습니다. 스웨디시·딥티슈·림프는 별도 가격을 만들지 않고 제공 여부/적용 요금 상담으로 구분했습니다.
9. 실제 운영 상호·운영자 정보·취소 조건이 확정되면 본문과 구조화데이터에 추가합니다. 가상 전화번호는 JSON-LD에 넣지 않았습니다.
10. 공개 후 Search Console URL 검사에서 렌더링, 색인 허용 여부, canonical을 확인합니다. 이 패키지 제작은 이즈웹 관리자에 자동 반영되는 작업이 아닙니다.

디자인: 블랙/핑크, 카드 호버, 은은한 광택, 하단 예약바 네온 맥동, 스크롤 등장 효과, 가이드 진행선. 동작 줄이기 설정 지원. 본문은 JS가 없어도 표시되며 FAQ는 기본 HTML로 작동합니다.
